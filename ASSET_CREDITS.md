# Asset credits and provenance

Starship Alexandria's code is MIT-licensed. Runtime art and audio are either
CC0 1.0 or project-original; bundled fonts are licensed under the SIL Open Font
License 1.1. Attribution is recorded even when CC0 does not require it.

`public/game-assets/manifest.json` is the machine-readable authority for exact
runtime SHA-256 hashes, source IDs, dimensions, and transformations. Runtime
files are committed and the game makes no asset-host requests.

## Pixel art

The four theme atlases and several silhouettes use selected cells from these
Kenney CC0 packs:

- [Roguelike/RPG Pack](https://www.kenney.nl/assets/roguelike-rpg-pack)
- [Roguelike Caves & Dungeons](https://www.kenney.nl/assets/roguelike-caves-dungeons)
- [Roguelike Modern City](https://www.kenney.nl/assets/roguelike-modern-city)
- [RPG Urban Pack](https://www.kenney.nl/assets/rpg-urban-pack)
- [Tiny Dungeon](https://www.kenney.nl/assets/tiny-dungeon)

Source cells are composed into a shared nine-role semantic grid, flattened
where a terrain role must be opaque, and scaled from 16px to 32px using
nearest-neighbor sampling. Book, journal, battery, map, transporter, loose-paper,
and terminal icons are project-original 16px integer-grid drawings generated by
the importer.

No Sketchfab thumbnails, photographs, Poly Haven textures, or remote runtime
images are included.

## Concept key art

`public/images/starship-alexandria-key-art.png` and its social-preview crop were
generated with OpenAI image generation through Codex on 2026-07-17. They are
showcase artwork only: no generated image controls collision, navigation, or
tile semantics. `public/images/manifest.json` records the exact prompt,
dimensions, transformations, SHA-256 hashes, and a visible AI disclosure.

## Audio

Kenney's CC0 [Interface Sounds](https://www.kenney.nl/assets/interface-sounds),
[Sci-fi Sounds](https://www.kenney.nl/assets/sci-fi-sounds), and
[RPG Audio](https://www.kenney.nl/assets/rpg-audio) provide interface,
transporter, ship-engine, book, and vault cues.

The following CC0 OpenGameArt works are imported from Beowulf's normalized
OGG/MP3 library:

- Fantozzi / qubodup,
  [Fantozzi's Footsteps](https://opengameart.org/content/fantozzis-footsteps-grasssand-stone)
  — stone and sand steps.
- TinyWorlds, from public-domain pdsounds recordings,
  [Different steps on wood, stone, leaves, gravel and mud](https://opengameart.org/node/5701)
  — dirt and leaf steps.
- Peludo,
  [Water Splash and sand footsteps](https://opengameart.org/content/water-splash-and-sand-footsteps)
  — shallow-water steps.
- HaelDB,
  [Footsteps Leather, Cloth, Armor](https://opengameart.org/content/footsteps-leather-cloth-armor)
  — equipment movement; the available CC0 license is selected.
- Voltiment555,
  [Book Flip Sounds](https://opengameart.org/content/book-flip-sounds)
  — page turns.
- Spring Spring,
  [Birds and Wind](https://opengameart.org/content/birds-and-wind-ambient-birds-wind-and-synth)
  — the ruins ambience; the source page credits its public-domain bird recordings.
- jasinski / qubodup,
  [Beach Ocean Waves](https://opengameart.org/content/beach-ocean-waves)
  — the garden ambience, looped with Beowulf's 600 ms end-to-start crossfade.

Every logical sound ships as an OGG/MP3 pair. The Kenney MP3 fallbacks are
deterministically transcoded from pinned OGG inputs with metadata removed.

## Fonts

- [Atkinson Hyperlegible](https://github.com/googlefonts/atkinson-hyperlegible),
  copyright Braille Institute of America, SIL OFL 1.1. Regular and Bold are
  bundled for interface text.
- [Literata](https://github.com/googlefonts/literata), copyright the Literata
  Project Authors / TypeTogether, SIL OFL 1.1. The Latin variable font is
  bundled for reading views.

The complete OFL texts are committed next to the font files in `public/fonts/`.

## Refreshing assets

Run `npm run import-external-assets` with pinned local Kenney and Beowulf source
collections, then `node scripts/validate-assets.mjs`. The importer stops rather
than accepting an unexpected input hash. Review visual diffs intentionally and
commit the regenerated outputs together with `manifest.json`.
